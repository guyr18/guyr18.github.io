REAL-TIME & DISTRIBUTED SYSTEMS

Robert Guy

Scheduling · Learning-Augmented Systems · Embedded / Edge / Cyber-Physical Systems

I study scheduling and resource arbitration in real-time distributed systems, with a focus on tail-tolerant performance under contention, uncertainty, and strict latency constraints. My research develops predictive and adaptive scheduling policies augmented with explicit runtime guard mechanisms to control extreme latency behavior.

RESEARCH

From robust state to protected prediction

My recent work follows a progression from distributed state synchronization to adaptive scheduling, predictive scheduling, and runtime protection against high-risk decisions.

State→Adaptation→Prediction→Protection
01

Distributed Scene Update

Middleware for real-time partial state synchronization in distributed systems, centered on partial, declarative, versioned updates and deterministic state handling.

Read preprint →
02

Adaptive Priority Arbitration

Runtime-aware arbitration for stateful distributed pipelines, using changing system conditions to adapt scheduling priorities rather than relying on fixed policies.

Read preprint →
03

Predictive Arbitration

Learning-augmented scheduling using sequence models to estimate the future cost of candidate scheduling actions from recent system history.

Read preprint →
04

Risk-Aware Guarded Scheduling

Runtime guard mechanisms for protecting predictive schedulers from high-risk decisions and controlling extreme tail-latency behavior.
